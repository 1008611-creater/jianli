# 刘曙宾 - AI Agent产品经理个人简历网站

这是一个现代化、美观的个人简历网站，用于展示刘曙宾的专业背景和项目经验。

## 特性

- 🎨 **现代化设计**：采用渐变色彩和卡片式布局
- 📱 **响应式设计**：完美适配桌面和移动设备
- ✨ **平滑动画**：滚动动画和交互动效
- 🚀 **快速部署**：一键部署到Vercel

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome 6.5.1
- Google Fonts (Inter, Noto Sans SC)

## 快速开始

### 本地预览

1. 克隆项目到本地
2. 打开 `index.html` 文件即可预览

### 部署到 Vercel

#### 方式一：一键部署（推荐）

点击下方按钮一键部署到 Vercel：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

#### 方式二：手动部署

1. 将代码推送到 GitHub 仓库
2. 访问 [vercel.com](https://vercel.com)
3. 导入你的 GitHub 仓库
4. 按照提示完成部署

## 自定义内容

### 修改个人信息

1. 打开 `index.html`
2. 找到对应的部分进行修改：
   - 个人信息（姓名、联系方式）
   - 教育背景
   - 工作经历
   - 技能
   - 作品集

### 修改配色方案

打开 `styles.css`，修改 `:root` 部分的 CSS 变量：

```css
:root {
    --primary-color: #6366f1;    /* 主色调 */
    --secondary-color: #8b5cf6;   /* 辅助色 */
    /* ... */
}
```
